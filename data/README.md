# Исходные данные и воспроизводимость

Данные получены из официальных источников **10 сентября 2026 года**. Дата получения не означает дату утверждения перечня. Поле `list_date` PDF ВАК — **2026-08-14**; у уровней Белого списка собственные годы 2023, 2025, 2026. Загрузка снимка сегодня не превращает его в список, действующий на сегодняшнюю дату.

## Что хранится

| Файл в `data/raw` | Содержание |
|---|---|
| `whitelist_2026-09-10.json` | Полный официальный экспорт Белого списка, 31 576 записей; 515 с `date_discontinued`, 31 061 без даты исключения |
| `whitelist_schema_2026-09-10.json` | Официальное описание JSON-экспорта |
| `whitelist_2079-3537_2026-09-10.json` | Реальный ответ API по ISSN «Научной визуализации» |
| `vak_2026-08-14.pdf` | Официальный перечень ВАК на 14.08.2026, 1 277 страниц, 3 229 номеров |
| `vak_parsed_2026-08-14.json` | Производные нормализованные Journal-записи, 3 202 принятые строки; это результат парсера, не самостоятельный официальный документ |
| `vak_parse_audit_2026-09-10.json` | 27 строк ВАК в карантине: 10 без ISSN и 17 с невалидной контрольной цифрой хотя бы одного ISSN |
| `vak_news_2026-09-10.json`, `vak_list_info_2026-09-10.json` | Ответы публичного интерфейса сайта ВАК, позволившие найти правильное текущее вложение |

Рядом с исходными файлами находятся `.meta.json`: URL, момент получения, размер и SHA-256. Для производного VAK JSON указан hash исходного PDF. Исторические названия и ISSN в названии журнала не превращаются автоматически в его текущие идентификаторы. Даты и строки специальностей сохраняются вместе; приложение не выдает юридическое заключение о применимости записи для конкретной защиты.

## Проверка и восстановление базы

Из корня репозитория, после установки проекта:

```powershell
# Только контроль hash/provenance. Ничего не записывает.
.\.venv\Scripts\python.exe scripts/rebuild_database.py --verify-only --use-validated-vak-json

# Полное восстановление из PDF и официального JSON.
.\.venv\Scripts\python.exe scripts/rebuild_database.py --db data/rebuilt.sqlite --audit examples/rebuild_audit.json

# Быстрее: использовать проверенный результат уже выполненного PDF-разбора.
.\.venv\Scripts\python.exe scripts/rebuild_database.py --db data/rebuilt-fast.sqlite --use-validated-vak-json --audit examples/rebuild_fast_audit.json
```

По умолчанию база — `data/sciagg.sqlite`, отчет — `examples/rebuild_audit.json`. **Файл существующей базы не удаляется**: записи дополняются или обновляются через Store. Для чистой реконструкции укажите новое имя базы, как в примерах. Не запускайте две записи в один SQLite-файл одновременно.

Разбор PDF занимал около **2–3 минут**, затем требуется время на сохранение десятков тысяч журналов. Быстрый вариант проверяет PDF, manifest производного JSON, связь двух hash, provenance всех записей и контрольную сумму отчета карантина; он не повторяет распознавание PDF. Моменты получения и исходные URL сохраняются. В обычном PDF-варианте момент получения берется из manifest, а время реконструкции отдельно записывается как `rebuilt_at`.

Файл аудита содержит принятые и отклоненные строки каждого источника, ошибки контрольных цифр и конфликты ISSN при сохранении. Число исходных строк не обязано совпасть с числом журналов SQLite: у журнала может быть несколько ISSN, он может присутствовать в обоих источниках; невалидные и неоднозначные записи помещаются в карантин. Непринятая строка не доказывает отсутствие журнала в официальном списке.

## Новые скачивания

```powershell
.\.venv\Scripts\python.exe scripts/download_sources.py --output data/downloads --source all --timeout 60
# Только небольшое описание схемы:
.\.venv\Scripts\python.exe scripts/download_sources.py --output data/downloads --source whitelist-schema
```

Каждое скачивание получает новое имя с UTC timestamp и отдельный manifest. Исходные снимки не перезаписываются. Используется обычный HTTPS с проверкой сертификатов, таймаутом чтения и лимитом размера 100 MiB; контроль общего времени выполняется между чтениями блоков. Ошибки входа, HTML вместо PDF/JSON, ограничения доступа и превышение лимита завершают соответствующее скачивание без обхода защиты.

URL Белого списка возвращает состояние сервера на момент нового обращения. URL ВАК в скрипте закреплен за проверенным **августовским PDF 2026 года**; скрипт не выдает его за самую новую будущую редакцию. Новые файлы не подменяют автоматически воспроизводимый снимок: перед использованием новой версии нужно проверить ее дату и формат, затем передать файл в соответствующую команду импорта CLI. `rebuild_database.py` намеренно восстанавливает именно проверенный комплект файлов с известными именами; `--raw-dir` позволяет указать копию этого комплекта.
