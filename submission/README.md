# rgau-lesson-1 — наукометрия

Учебный проект магистратуры по наукометрии. Отчёт объясняет российские и международные источники, а **SciAgg RU** на Python 3.12+ демонстрирует поиск авторов и публикаций, объединение библиографических данных и расчёт показателей с сохранением их происхождения.

## Что выполнено по заданию

| Тема | Результат |
|---|---|
| РИНЦ / eLIBRARY | Исследованы различия и доступ; реализован импорт разрешённых выгрузок. Прямой договорный API не проверен. |
| ВАК | Исследован перечень 2026 года; реализованы разбор официального PDF и импорт с аудитом. |
| Белый список | Исследованы уровни и даты; работают API по ISSN и импорт официального JSON. |
| Scopus | Исследован; провайдер реализован. Для живого доступа нужны ключ и соответствующие права; авторизованные ответы не проверены. |
| Цитирования | Сбор и объяснение отдельных счётчиков каждой базы без суммирования. |
| h-index | Объяснение, реализация и тесты; для `[10, 8, 5, 4, 3, 1]` результат **4**. |
| Квартили журналов | Объяснение, модель и импорт с обязательными системой, годом и предметной категорией. |
| Поиск автора и публикаций | Поиск кандидатов, выбор устойчивого ID, профиль и публикации. |
| Различение однофамильцев | Консервативное сопоставление по ID, DOI и контексту; неоднозначности требуют проверки. |
| Объединение источников | Дедупликация публикаций, сохранение альтернатив и происхождения полей. |
| API / парсер / агрегатор | Crossref, OpenAlex, ORCID, российские реестры, SQLite, экспорт JSON/CSV/XLSX. |

## Быстрый запуск

Python 3.12+; PowerShell. После скачивания архива откройте его папку и начните с создания окружения.

```powershell
git clone https://github.com/thinganother675-lab/rgau-lesson-1.git
cd rgau-lesson-1
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m sciagg demo
```

Установка зависимостей требует Интернета; затем демонстрация работает без сети и ключей. Команды для Linux/macOS, тестов и других сценариев — в [README_RU.md](README_RU.md).
