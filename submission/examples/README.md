# Демонстрационные данные

`demo_profile.json` — результат реальной агрегации трёх работ профиля J. E. Hirsch, OpenAlex A5036688434. Даты каждого API-ответа находятся в provenance; h по этой части равен 3 у двух источников. Это не полный h-index автора. `python -m sciagg demo` читает этот файл без сети.

`hirsch_article.json` — статья 2005 года с DOI 10.1073/pnas.0507655102. Crossref и OpenAlex дают разные наблюдения цитирований; они сохранены отдельно.

`orcid_profile.json` — публичный ORCID-профиль и две работы по точному ORCID-фильтру Crossref, дополненные OpenAlex. Полнота не заявляется.

`demo.csv` и `demo.xlsx` — результаты встроенного экспортера. Рядом лежат полные `.profile.json`: Excel не подходит для хранения неограниченно длинных исходных JSON внутри ячеек. JSON является основным полным экспортом.

`live/` — реальные ответы трёх авторских примеров и скрипт повторения сетевого эксперимента. `templates/` — отдельные **синтетические** шаблоны импорта; не используйте их как реальные показатели журналов. Программные тесты используют synthetic fixtures непосредственно в тестах каталога `tests/`.

`vak_import_audit.json` и `rebuild_audit.json` — фактические результаты импорта, включая карантин и конфликты при сохранении. Счётчик принятых исходных строк не равен числу уникальных журналов SQLite.

Свежий запрос может дать другие показатели. Не подменяйте дату старого ответа сегодняшней датой; повторный offline-прогон сохраняет время получения источника.
