4. [README_RU.md](README_RU.md) — подробная инструкция; [examples/demo.xlsx](examples/demo.xlsx) — готовый табличный результат.

## Запуск из распакованной папки

Нужен Python 3.12+. Откройте PowerShell в папке, содержащей этот файл и pyproject.toml:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m sciagg demo
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ruff check src tests scripts
```

Интернет требуется для первоначальной установки зависимостей. Затем demo и 88 тестов работают без сети и API-ключей. Готовые отчёт, таблицы и сохранённые ответы доступны сразу. Linux/macOS: замените первую команду на `python3.12 -m venv .venv`, а путь к Python на `.venv/bin/python`.

## Что входит в компактную версию

Папка `submission/` и архив `rgau-lesson-1-submission.zip` содержат отчёт, инструкции, источники, исходный код, тесты, скрипты и небольшие реальные/синтетические примеры. В архиве файлы лежат непосредственно в корне; распакуйте его в отдельную папку. Ключи, окружение Python, кэши и SQLite-базы не распространяются. Файл `SUBMISSION_MANIFEST.json` содержит контрольные суммы SHA-256 материалов пакета.

Полные реестры ВАК и Белого списка не дублируются в компактном пакете. Для полного повторения импорта восстановите исходные снимки по [data/README.md](data/README.md). Проверка `scripts/check_project.py` включает контроль этих снимков и требует полного набора; для компактной версии используйте три отдельные команды demo, pytest и Ruff выше. Демо не требует восстановления базы.

Срез данных — 10.09.2026. Три статьи демонстрационного профиля — неполная выборка; её h-index не является полным показателем автора. Счётчики разных баз сохраняются отдельно, квартили относятся к конкретным системе, категории и году. Живой Scopus требует прав; прямой доступ eLIBRARY ограничен доступными условиями.

## Передача материалов

На общий диск можно загрузить архив или содержимое папки `submission/`. Ссылки для отдельного документа — [SUBMISSION_LINKS_RU.md](SUBMISSION_LINKS_RU.md), короткое сообщение — [SUBMISSION_NOTE_RU.txt](SUBMISSION_NOTE_RU.txt).

Для повторной сборки пакета из исходного репозитория выполните:

```powershell
.venv\Scripts\python.exe scripts/build_submission.py
```

Скрипт копирует только явно перечисленные материалы, обновляет папку и ZIP. Перед сборкой выполняйте тесты и проверки из README_RU.md.
