# Пять минут перед занятием

1. Открыть [CLASS_TODAY_RU.md](CLASS_TODAY_RU.md). Прочитать первый ответ и название темы.
2. Открыть [SELECTED_ARTICLE_TOPIC_RU.md](SELECTED_ARTICLE_TOPIC_RU.md): вопрос, гипотеза, baselines, метрики и MVP. Честно сказать: это план статьи, эксперимент ещё не завершён.
3. Открыть [README.md](README.md) и [examples/demo.xlsx](examples/demo.xlsx). Это готовый результат агрегатора; демонстрационный профиль не является полным профилем автора.
4. В PowerShell из корня проекта выполнить команды ниже. Интернет и API-ключи не нужны.
5. Если спрашивают регистрацию: открыть [ELIBRARY_STATUS_RU.md](ELIBRARY_STATUS_RU.md). Сейчас 403, вход пропущен. После восстановления доступа открыть официальный [eLIBRARY](https://elibrary.ru/), самостоятельно войти и показать персональную карточку/SCIENCE INDEX; не создавать дубликат автора наугад.

```powershell
.venv\Scripts\python.exe -m sciagg demo
.venv\Scripts\python.exe -m sciagg h-index 10 8 5 4 3 1 --json
```

Если нет времени запускать: показать готовую таблицу и [свежую проверку](VALIDATION_2026_09_30.md). Для WoS открыть [короткое объяснение](docs/WEB_OF_SCIENCE_RU.md). Для доказательства доступности данных темы — [реальный недельный ответ NASA](examples/research-2026-09-30/nasa-weather-week.json); это пример исходных данных, а не результат нового аграрного алгоритма.

Для передачи преподавателю: актуальный rgau-lesson-1-submission.zip. Для вопроса «откуда требования?» — [матрица реконструкции](ASSIGNMENT_RECONSTRUCTION_RU.md). Парсер необязателен по доступной переписке; регистрация и тема добавлены как требования, выведенные из сообщений группы.
